# CHIRON web: design contract

System: `linear.app` from ~/.config/design-md (near-black product canvas, tiered surfaces, hairline borders, one accent), adapted to a ledger page. Tokens live in `src/tokens.css`; components read only tokens.

1. **Direction:** an operator console for one agent trading account. Near-black canvas, three surface tiers, 1px hairlines, one accent used only for the primary action, focus and the sheet's 2px top rule, and that accent is the selected network's own color (Robinhood Chain lime #c3f53c, Arbitrum blue #28a0f0; #5e6ad2 fallback), so the page says which chain it reads before any text does. Status is carried by semantic chips: executed/admitted/verified green, proposed (waiting on the owner) amber, refused calls and failed receipt checks red, admin and configuration states neutral.
2. **Fonts:** Archivo Variable (display + body, self-hosted via @fontsource-variable/archivo, wdth axis) and IBM Plex Mono 400/500 (@fontsource/ibm-plex-mono) for addresses, hashes, amounts and block numbers. No Inter/system face: Archivo's semi-condensed width gives the metrics a tighter, instrument-panel look than Linear's Inter.
3. **Palette (CSS variables):** --canvas #08090a, --surface-1 #0f1011, --surface-2 #141516, --surface-3 #1b1c1e, --hairline #23252a, --hairline-strong #34343a, --ink #f7f8f8, --ink-muted #d0d6e0, --ink-subtle #8a8f98, --accent per network ([data-chain] in tokens.css: #c3f53c / #28a0f0, fallback #5e6ad2), --ok #3ec6a8 (mint, kept clear of the lime accent), --warn #e3b341, --bad #f2555a; chain dots RHC #c3f53c, Arbitrum #28a0f0.
4. **Spacing / type:** 4px base: 4 8 12 16 24 32 48 64. Type scale 12/14/16/20/28/44; gate values 20 mono tabular; labels sentence case, never uppercase-transformed. Radius 6 (controls), 10 (sheet and panels), pill for chips. One shadow only for real elevation (wallet menu, tx toast).
5. **Layout:** top bar (wordmark, chain switch, wallet) → one sheet: headline + the single primary action ("Recheck every receipt", with its verdict in place), then the signature strip: the four checks every call passes (quote, code, caps, receipt) joined by a rail, each with its live state and how many refused calls were stopped at that step (refusals mapped by custom error) → ledger of activity on the canvas (left) and a sticky Policy panel with caps (right) → owner controls as a collapsed disclosure row. Under 1000px one column with Policy before Activity.
